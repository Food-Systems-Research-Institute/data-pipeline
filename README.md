# Data Pipeline

## Development

Clone repository

```sh
git clone https://github.com/Food-Systems-Research-Institute/data-pipeline.git
cd data-pipeline
```

Set up environment with uv ([uv installation](https://github.com/Food-Systems-Research-Institute/data-pipeline.git)).

```sh
uv sync
```
